    MedCore.Session (med_ex v0.1.0)

    Copy Markdown View Source

    Immutable live clinical transport session aggregate and pure reducer seam.

    A Session owns live participants, WebRTC connection attempts, signal integrity state, device capture continuity, and control interlocks. It can outlast individual browser peer connections (connection_id) and supports standalone capture (acquisition_id) with or without an external clinical encounter_ref.
