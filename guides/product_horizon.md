# Product scope

The supported release provides technical waveform/event evidence and independent
optional codec/RTC packages. Fabric composes clinical authorization, review,
manual pulse, paired audio/ECG, PLX events and browser microphone capture.

Physical-device calibration, diagnostic interpretation, clinical readiness,
browser offline durability, writable multi-node failover and additional storage
backends are outside this release. Keep no dormant implementation for these
features. A new use case must justify its ownership, actual behavior and tests.
Synthetic/reference sources qualify software behavior only.
