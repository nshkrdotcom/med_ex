# MedAdapters v0.1.0 - API Reference

## Modules

- [MedAdapters](MedAdapters.md): Opt-in behaviour-driven signal compute and external media adapter layer for
MedEx (`MedAdapters.Inference`). Excluded from the default `:med_ex` SDK
projection until a concrete adapter proves clean-consumer compatibility.

- [MedAdapters.Inference](MedAdapters.Inference.md): Behaviour contract for advisory clinical inference adapters (e.g., Ortex/ONNX).
